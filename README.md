# MSW Earnings Bingo

## Nutzung

Einfach [`msw-earnings-bingo.html`](msw-earnings-bingo.html) im Browser öffnen – kein Server, kein Build, keine Installation nötig.

- **Feld erstellen:** Über das Zahnrad Begriffe anpassen, Feldgröße (3×3 bis 7×7) und Farbe wählen.
- **Treffer zählen:** Klick auf ein Feld = Treffer (+1), Rechtsklick = Treffer abziehen (-1).
- **Bingo:** Bei einer vollen Reihe/Spalte/Diagonale gibt's die Feier-Animation.
- Der Fortschritt wird lokal im Browser gespeichert (`localStorage`), es werden keine Daten irgendwohin übertragen.

## Tech

Reines HTML/CSS/JavaScript in einer einzigen Datei – kein Framework, keine Abhängigkeiten.
